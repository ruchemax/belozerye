# Белозерье

Статическая электронная библиотека писцовых книг Белозерского уезда.

Готовая версия сайта находится в каталоге `dist`. Для локального просмотра можно запустить любой статический сервер из корня проекта, указав `dist` как корневую папку.

- `/` — главная страница со списком книг.
- `/books/belozersky_uezd-1626-27/` — писцовая книга Н. Шеховского и М. Козлова 1626/27 года.
